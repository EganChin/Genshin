# 剧情问答：原文与结论的对应示例

这是一份回答方式示例，不是可直接套用的剧情结论。实际回答须重新查询对应文本，按用户的问题选择相关原文；不必机械照搬标题或格式。

假设用户问：某人为什么寻找同伴很久？他们是怎么分散的？查询结果分别是：某人的日志写明寻找「近百年」、记载同伴在巨大迷宫里且自己多次寻找无果；目击者只说看到同伴被一个身份不明的人带走。则可以这样回答：

> 某人在日志中说：「那近百年的旅程……」因此可以确认他经历了近百年的寻找。
>
> 关于为什么费时，日志写道：「那座迷宫无边无际，而她就在其中某处。」他还记载多次寻找无果。迷宫的规模和未知位置说明寻找困难，但原文没有给出精确耗时的计算机制。
>
> 关于分散的经过，目击者说：「我看见一个陌生人带走了她。」这能说明有人带走她，但单凭这句话无法确认对方身份、动机或她进入迷宫的具体经过；这些还需要查证。

以上人物、引文和情节均为虚构，不能作为游戏资料引用。注意：寻找时长、费时原因、分散经过是三个不同问题；某人表达「无论多久都会找到她」只能证明决心，不能证明实际寻找时间或分散原因。不能把之前的分头行动或另一段漫长经历当成这次失散的原因。未能检索到资料时说明未查到，不等于该事实不存在。
